GitHub commands:
	git add . -> adds all files to be uploaded
	git commit -m "notes go here" -> commits to GitHub with notes
	git push -u origin master -> actually uploads the folder to GitHub

	git restore -> if you accidentally made changes before pulling, use this to restore so that you can pull (ONLY USE IF THE CHANGES YOU MADE ARE UNIMPORTANT)
	git pull -> pull and download stuff from github

PI commands:
	SSH germinc1@germinc1 -> remote access to pi
	source env/bin/activate -> activates virtual environment (do this in the folder /~ everytime)
	htop -> see performance stats

	ls -> list all files in the current directory (-a for hidden files)
	cd -> change directories
	touch -> make a file in the current directory
	mkdir -> make a folder or new directory under the current directory

	python3 "script name" -> runs script with python
	sudo nano "script name" -> opens the script with the nano script editor

NANO commands:
	ctrl + O, enter -> save
	ctrl + X -> quit
